## 🧭 About Me

I'm a **generalist**. I don't start from a tool or a title. I start from the problem, then learn whatever it takes to solve it.

My way of working is simple: **try, err, improve.** I build something, see where it breaks, understand why, and make the next version better.

- 🌐 I know a bit of **front end** and **back end**, and I'm getting better at both
- 🛡️ I enjoy **security** and practice on TryHackMe and Hack The Box
- 🔭 I keep exploring other tech, because the next problem may need it
- 🤝 Open to roles where I can learn fast, take ownership and keep progressing
